# OpenRouter release history

v1.0.0 (2026-11-11, first release): An AI route for OpenRouter and any OpenAI-compatible /chat/completions server.

NEW: OpenRouter's models in SlideMage, with your own key.
- Use any model OpenRouter offers for chat, image descriptions, translation and fixes: paste your key under Settings → AI → OpenRouter and choose a model in AI setup.
- Works with any OpenAI-compatible server too (OpenAI, LM Studio, vLLM, Ollama's /v1): set its base URL, and a key if it needs one.
- Add a model the server does not list under Extra model IDs.
- Check connection shows whether the server and key work, and how many models it offers.
